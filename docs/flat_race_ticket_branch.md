# 平場の券種分岐と買い目候補

2026-10-04実装。比較候補のみ。本番の自動購入・モード設定・予測印は変更していない。
重賞B/K、障害、新馬はこの比較の対象外。新馬除外は既存の運用方針を維持した。

## 先に券種、次にフィルター、最後に組合せ

1. 5頭以下は無条件で見送り。
2. 6〜9頭は3連単候補。
3. 10頭以上は原則3連複。突出軸の条件を満たす場合だけ3連単候補。
4. 券種に応じた信頼度条件を満たさなければ見送り。
5. 合格した券種で出走馬の採用順位から実際の馬番の組合せを作る。

突出軸候補は「軸のU指数が他馬の最高値より3または5以上高い」「軸がML勝率の首位」
「レース内で正規化した軸のML勝率が25%または35%以上」の組合せ。
これらのML数値が実測勝率に較正済みとは仮定しない。基準は調整可能な検証候補。
結果人気・確定オッズ・Umanityみんなの人気は選択器に使わない。

券種別に3通りの組合せ、突出軸3通り、信頼度3通りの81候補を比較。
6〜7月と8月で候補を選び、その後に固定した候補の9月結果を評価した。
候補選定の最低条件は両期間40レース・10的中・的中率20%・参加率30%。
合格候補の両期間回収率の低い方を最大化する。これは「最高の設定」を証明する条件ではない。

## 今回残った比較候補

- 3連単: 採用順位1位を1着固定、2〜5位を2・3着に置く12点。
- 3連複: 上位4頭BOXの4点に、上位2〜3頭と5・6位の組合せなど8点を追加する12点。
  順位をA〜Fとすると、ABC/ABD/ACD/BCD、ABE/ABF/ACE/ACF/BCE/BCF/ADE/BDE。
- 信頼度: 3連単は軸のML3着内値60%以上、3連複は上位5頭のML3着内値の平均30%以上。
- 突出軸の候補条件: U差5以上、正規化ML勝率35%以上。ただし該当レース0で有効性未検証。

実際の印と採用順位が異なる場合、この候補の軸は採用順位1位。印の◎を勝手に入れ替える処理ではない。

## 同一レース・同一予算の結果

1レース1,200円。既存の自動モードの買い目は相対的な配分を保ち、100円単位の
最大剰余法で1,200円に正規化した。端数は元の買い目の順序で解決する。
本来1,000円のモードも1,200円にそろえているため、実際の購入履歴の成績ではない。
手動モード上書き・購入時Viewerも再現していない。

|---|---:|---:|---:|---:|---:|
|2026年6〜7月|415|12.77%|28.19%|50.98%|74.81%|
|2026年8月|261|18.01%|30.27%|99.02%|72.34%|

9月の共通予算は200,400円。既存117,870円、候補179,530円の払戻。
損失は82,530円から20,870円に縮小したが黒字化していない。
9月の候補回収率の日単位ブートストラップ95%区間は60.78〜115.78%。
最大払戻の1レースを除くと回収率73.60%で、安定した利益の証拠ではない。

券種を全て3連複に固定した比較は、9月の的中率31.14%・回収率84.95%。
分岐候補は的中率を4.19ポイント下げ、回収率を4.64ポイント上げた。
同じ分岐の回収率改善は6〜7月+3.20ポイント、8月+1.42ポイント。
全て3連単の場合は9月の的中率9.04%・回収率62.35%（信頼度による見送りで166レース）。

6〜9頭だけでは9月24レース・7的中・的中率29.17%・回収率59.62%。
少頭数なら利益が出るとはいえず、1着固定の信頼度と購入条件の追加検証が必要。

現行の自動選択条件に該当する9月の129レースに限ると、候補は1レース見送り、
128レースで的中率26.56%・回収率81.45%。上の167レース全体の数字と混同しない。

## データ上の限界と採用判断

完全な平場848レースを比較。取消・出走馬不一致91、同着等4レースは除外した。
重賞35、障害36、新馬138も対象外。取消時の返還を含む購入成績ではない。
Predict/Resultsの馬番集合、重複キー、上位3着と払戻を確認し、必要なファイルを1回読み込む。
各入力ファイル、コード、買い目設定の指紋をレポートに記録した。masterの再マージや再収集は不要。

848レース全てで保存予測のモデル版・学習時点・実行環境の記録が不明だった。
時系列分割だけでは学習リークがないと証明できない。6〜9月自体も以前の比較で既に確認済みの期間。
したがって今回は後追い診断であり、最新モデルの未使用期間での採用検証ではない。
8月回収率が悪化し全期間100%未満のため、本番への自動採用は行わない。

2026-10-04のPredictにはモデル方式`calibrated_lr_with_place2_actual_market_v2`、
モデル版`2026-10-03.actual-market-profitability-v8`が記録されている。
7/4、8/1、9/27の平場の軸ML3着内値中央値は90.5%、87.6%、85.4%だが、今日の平場は56.6%。
確率の数値分布が大きく違うため、過去データから選んだ60%等の閾値を現行モデルに直結しない。
当日の出力も「モデル互換性未検証」の比較候補。現行モデルと学習時点を記録した
過去予測の再試算、または今後の未使用データでフィルターを較正してから採用判断する。
