# 収益性改修・比較結果（2026-10-03）

予測リリース: `2026-10-03.actual-market-profitability-v8`。
ソースへの組込みは済み。既存Predict・Viewer・購入予約・実投票設定はこの作業では再生成・変更していない。

## 通常実行に入れた修正

- 勝負判定を最終採用順位の決定後に作る。ML／補正方式の切替前に作った判定や古い◎の人気・能力差を残さない。自信度自体は選択された基礎モデルの値であり、利益確率に読み替えない。
- 期待値用の勝率をレース内で合計1に正規化する。元のMLスコア・印は変更しない。入力欠損・範囲外・合計0なら期待値は欠損。これは確率の整合であり、校正の保証ではない。
- P12にB/K用の「▲特殊印→○軸」の入替が漏れていた問題を修正。12点の意図的な列重複が崩れて18点となり、購入を停止するケースを過去データで5件検出。B/Kの既存入替規則は維持する。
- 収益選別の推定回収倍率・判断理由・評価モード・投資額をPredictとViewerのレース情報に追加。予測モデル版／方式・実行環境・市場入力方式・買い目設定・評価期限が一致しない収益モデルは使わない。
- 購入画面に「検証済み収益候補だけに絞る」を追加。既存条件へのAND条件であり、利益候補を理由に別のレースを追加購入しない。既定OFF、未検証は対象外。フルオートは購入直前にも最新CSVの条件を再確認する既存経路を使う。

新しい研究コードは `purchase_system/analysis/validate_profitability_selector.py`、共通推論・特徴・比較買い目は `profitability_selector.py`。
正常な通常予測を再学習・再生成したことや、購入画面の実ブラウザ操作まで確認したことを意味しない。

## 回した比較

2026-06-01～09-27の保存Predictを、現在の購入コードと同じフォーメーション展開で評価。
1,008完全レースが対象。結果欠損・取消等139レース、同着等で1～3着が一意でない5レースを除外。
保存Predictの印からの理論比較で、購入時Viewerの印・実際の投票履歴の再現ではない。
旧CSVにモデル来歴がないため、新しい実市場限定モデルの性能証明には使わない。

収益モデルは6～7月で学習、8月だけで候補選定、9月で凍結評価。結果・払戻・確定オッズ・みんなの人気は特徴量に入れない。
実際の払戻／投資額で学習し、極端な高配当は学習時だけ20倍に抑える。評価払戻は抑えない。
構造・確率・モデル合意・脚質・コース・競馬場の6群を一群ずつ除去して比較。Ridgeの強い正則化を使用。
日別の最大6レース、推定回収倍率1.0または1.1以上。件数を埋めるための購入はしない。
今回、十分な候補数と収益性の基準を満たす選別モデルはなかった。候補モデルは研究用出力にのみ保存し、`config/profitability_selector.pkl`には設置していない。

### 確率診断

旧保存予測の9月139対象レースで、◎の元勝率平均87.621%に対し実勝率30.935%。レース内勝率合計も平均約5.16。
レース内正規化後の、レース等重みの馬単位Brierは0.20148→0.06907、二値LogLossは0.60364→0.24810。
元勝率の順位は保持。能力期待値だけが整合した勝率を使う。新しい通常校正モデルの誤差や実購入回収率がこの数値になったという主張ではない。
