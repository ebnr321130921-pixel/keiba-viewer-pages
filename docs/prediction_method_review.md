# 予測メソッドの精査（2026-10-10）

## 処理の順序

過去走の能力・脚質・上がり・時計・適性 → 騎手／厩舎／年齢の集計 → U指数の標準化・条件特徴 → 1着／2着／3着内の確率学習・校正 → 主軸・対抗・紐の順位 → 場別・開催序盤・実人気変動の追加補正 → 調教の紐補正 → 爆・飛と安全な軸 → Viewer／購入計画。

確率モデルの効果と、その後の固定加点・買い目選択の効果は別に評価する。全ての加点が学習された係数ではない。

## 修正した実装上の問題

- 購入パネルは画面終了後も独立して動くが、旧起動処理は応答の有無だけで再利用していた。コードの指紋を比較し、停止中の古いサーバーだけを入れ替える方式へ変更。監視が有効な場合や別プロセスの場合は自動終了しない。
- 当日予測と回収率の診断で、▲・△の並べ方が異なっていた。`final_rank_pipeline()` を共有し、別の古い順位計算を削除した。追加補正や買い目方式を含む評価は、その条件も明記する。
- 重み付きスコアの係数学習は、全欠損列が補完処理で脱落すると係数と列名が合わず、固定値へ黙って戻っていた。現行入力では `_sw_delta_value` が該当する。失敗が確定している2回の学習を省き、固定値か学習値かをログ・方法名に残す。未検証の代替係数は自動採用しない。
- レースごとの正規化を47箇所でまとめて計算する方式へ変更。欠損・定数・非有限値の扱いを保持した。同一入力1,600頭について元の順位処理と共有後の順位・スコア・妙味指数が完全一致することを確認した。キャッシュを使う実行は約77秒から24〜26秒（当日入力更新を含むため、予測結果の不変性は同一入力比較で確認）。
- モデル再学習の判定を予測日単位から学習入力の内容単位へ変更。入力特徴、結果ラベル、日付、学習方式、実行環境のいずれかが変われば作り直す。同じ学習を日付だけの違いで繰り返さない。当日のオッズ・調教・予測・購入計画は都度更新する。

## 検証する候補

学習は2023〜2024年、候補選択は2025年、最終確認は2026年。確率のBrier／LogLossと、同額のR12口・95点・参考10点BOXを比較する。過去の予測CSVは書き換えない。

| 候補 | 検証目的 |
| --- | --- |
| 固定の脚質・距離・コース加点を外す | 学習モデルとの二重加点が買い目を悪化させていないか |
| 妙味加点を外す | 実オッズ不足時の二重スコア化と役割への影響 |
| △4・△5の妙味枠を能力枠へ戻す | 下位の紐枠が恣意的な補充になっていないか |
| 確率だけで主軸・対抗・紐を決める | 複雑な役割補正の必要性 |
| 欠損・定数・重複特徴の削減と別ソルバー | 123特徴から104特徴へ整理した場合の精度と学習時間 |
| 騎手・厩舎・年齢を各対象日の前日までで集計 | 学習期間内の自己参照・未来の集計を避ける案 |
| 人名カテゴリを外す | 多数の固有名カテゴリによる過学習と計算負荷 |

旧騎手・厩舎集計は学習期間全体を参照し、年齢表も同じ学習データへ適用していた。「最近1年」も対象日ではなく学習期間の末尾を基準にしていた。各対象日の前日までへ修正し、同日の結果も除外する。将来結果を追加しても以前の特徴が変わらないことをテストする。

古い勝ち馬の脚質バイアスも学習対象自身や同じ年の後日の結果を参照していた。学習行へ付与する表を対象年の開始前の履歴で作る方式へ修正。別途のコース交互作用は既存の日付ごとの過去集計を維持する。ユーザーの追記に従い、これらの情報時点の誤りは多少の回収率・的中率の低下があっても修正する。

## 既存の実験補正

開催序盤の「平均＋1σ」は日間のばらつきを加点するユーザー指定の暫定ルールで、統計的な確信度ではない。既存の保存予測比較では回収率の安定した改善はなかった。場別補正は実行環境・モデル方式の不一致時に適用されない。実人気変動は発走前の複数時点の実オッズが必要で、歴史データ不足時には収益効果を主張しない。

改善しない候補を、単に複雑だからという理由で全体へ適用しない。採用・保留の最終結果は[検証JSON](../outputs/prediction_method_audit_20261010/report.json)に記録する。

## 採用結果

情報時点の修正＋19特徴の削減＋LBFGS/C0.5を採用し、名前カテゴリは維持した。学習時間は約204〜212秒から15秒へ、キャッシュを使う予測全体は約77秒から25秒へ短縮。順位重みは今回の比較と同じ固定値に揃え、本番の混合年度での自動探索を削除した。おすすめ判定の閾値も候補選択年だけから決める。

平場R（各12口・1,200円）の回収率は2025年78.11%→83.66%、2026年73.45%→75.70%。2026年の的中数は614→619。レース選別前の基礎順位比較であり、実購入収支や追加の調教補正の改善幅とは別。

重賞だけの95点参考比較は2026年67.10%→57.78%で、改善とは扱わない。ユーザー指定に従いRを優先して採用し、95点の買い目方式は維持した。詳細と対象数は[検証結果](../outputs/prediction_method_audit_20261010/summary.md)を参照。

この比較はアーカイブから再構成した理論買い目で、実購入履歴の収支ではない。保存された基礎特徴には取得時点が発走前と確認できないものもある。Rと95点の結果は予算・対象レースを分けて読み、今回の改善幅を前回の調教補正へ足し合わせない。
