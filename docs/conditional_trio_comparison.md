# 3連複の軸数・点数・突出度の比較

2026-10-04。2頭軸6点・各200円、および突出度でBOX・1頭軸・2頭軸を
切り替える方式を実装して比較した。本番は変更せず、比較候補として保持する。
前回の最終表で最高回収率だったのは4頭BOXの109.19%であり、5頭BOXではない。
5頭BOXは的中率と6〜7月・8月の選定条件を満たす暫定候補。

## 切替ロジック

結果を参照しない候補専用処理は`purchase_system/analysis/flat_trio_routing.py`。
既存のViewer契約に沿う候補順・飛印除外・乗り替わり優先を共通処理から使う。

1. 上位2頭の弱い方が、他の全馬より突出していれば2頭軸。
2. それ以外で上位1頭が他の全馬より突出していれば1頭軸。
3. 突出がない、または必要な信号が欠けていれば軸なしBOX。

信号はU指数差と、ML勝率のレース内相対差を別々に比較。
相対差は`(軸側の最低値 − 他馬の最高値) / max(両者)`。
単純な絶対確率閾値は使わない。相対差も現行モデルへの互換性・確率校正を保証しない。
候補から除外した飛印馬も「他馬の最高値」の比較には含める。

1頭軸は相手5頭10点と相手4頭6点、2頭軸は相手6頭6点と最大12点を比較。
片方の突出条件のみ有効にした候補も含む。固定買い方8通りと条件切替96通り、計104候補。
2頭軸の相手は候補順から取る。別の軸ペアや券別EVで相手を選ぶモデルではない。

## 同じ161レース・1,200円の結果

完全な平場867レースから現在の3連複分岐761レースを対象にした。
6〜7月366レースで探索、8月234レースで選定し、9/1〜10/3の161レースで比較。
取消・同着・不完全レースは除外。必要候補8頭未満も除外する規則だが、今回は該当なし。
全期間が既に別の分析でも使われた保存データであり、新しい将来検証ではない。

|買い方|的中数・的中率|払戻|回収率|
|---|---:|---:|---:|
|5頭BOX・10点、総額1,200円|36 / 22.36%|173,970円|90.05%|
|2頭軸6点・各200円|24 / 14.91%|95,000円|49.17%|
|1頭軸6点・各200円|28 / 17.39%|126,500円|65.48%|
|2頭軸最大12点・総額1,200円|32 / 19.88%|173,430円|89.77%|
|探索・選定期間で事前に選んだ条件切替|34 / 21.12%|171,790円|88.92%|

選定ルールは両期間40レース以上、10的中以上、的中率20%以上を要求し、
6〜7月・8月の回収率の低い方を最大化。比較期間の結果はこの選定に使っていない。
選ばれたのは「2頭のU指数差0.5以上なら最大12点2頭軸、
それ以外で1頭のU指数差5以上なら6点1頭軸、残りBOX」。
6〜7月は84.15%、8月は98.54%だが、比較期間ではBOXの90.05%を下回った。
小頭数3連単側も含めると、この切替候補は回収率84.66%、現在方式は85.64%。

点数を半分にして200円にすると、残した的中券の払戻は増える。
しかし軸馬が3着内に入らないレースや、削った相手での的中を失う。
総予算をそろえた場合、200円にするだけでは回収率は改善しない。

## 正確に10点×100円対5点×200円

同じ161レース、双方総額161,000円。BOX側は100円均等で、前表の1,200円配分とは異なる。

|買い方|的中率|払戻|回収率|
|---|---:|---:|---:|
|5頭BOX10点・各100円|22.36%|160,790円|99.87%|
|2頭軸5点・各200円|11.80%|75,460円|46.87%|

均等1,000円BOXの回収率が1,200円BOXより高いのは、1,200円版で追加購入した
2通りの成績がこの期間では弱かったため。配分変更も別途検証すべきで、
比較期間を見てこの配分だけを即採用する根拠にはしない。

## 100%超の探索候補と限界

104候補の比較期間の最高値は次の条件で100.97%、的中率23.60%だった。

- 上位2頭のML勝率相対差15%以上なら2頭軸6点。
- それ以外で上位1頭の相対差25%以上なら1頭軸6点。
- 残りは5頭BOX。総額はすべて1,200円。

これは比較期間を見た後の最高値であり、事前選定された勝者ではない。
6〜7月74.79%、8月93.13%、比較期間100.97%。最後の期間だけ100%を超えた。
比較期間の収支は+1,870円、日別ブートストラップ95%区間は71.40〜130.49%。
最大払戻を除くと84.38%。安定利益の証明ではない。

同候補の内訳は、2頭軸40レース70.88%、1頭軸26レース81.73%、
BOX95レース118.90%。100%超を「軸を固定すると強い」とは解釈できない。

743レースはモデル来歴不明、18レースは10/3のv6。現行v8の独立検証ではない。
保存Predictによる再試算で、購入時Viewer・実購入履歴や券別オッズの再現ではない。
104候補からの最高値には過学習リスクがあり、この候補と閾値を固定した未使用期間の検証が必要。
